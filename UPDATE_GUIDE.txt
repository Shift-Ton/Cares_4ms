CARES DASHBOARD — FILE UPDATE GUIDE
===================================
Revision: Transparent continuous-growth loader + offline tree-fall sequence
Date: July 26, 2026

FILES THAT MUST BE UPDATED
--------------------------
1. index.html — REQUIRED
   Replace your current index.html.

   Why it changed:
   - Adds a shared SVG group around the living tree parts.
   - This lets the full tree fall naturally when internet access is lost.
   - Keeps the existing CARES logo and offline modal.

2. style.css — REQUIRED
   Replace your current style.css.

   Changes:
   - Removes the white loading popup/card background.
   - Keeps the loading layer transparent.
   - Blurs only the dashboard, table, sidebar, and content behind the loader.
   - Adds smooth percentage-by-percentage tree growth styling.
   - Adds continuous movement while a very slow backend remains at 99%.
   - Adds the tree-fall, branch-break, and leaf-disconnect animations.
   - Retains the falling-apple animation when loading finishes successfully.

3. script.js — REQUIRED
   Replace your current script.js.

   Changes:
   - Percentage displays 0%, 1%, 2%, 3% and continues one whole number at a time.
   - Backend milestones can change the loading message but cannot make the
     visible percentage jump.
   - Initial loading has a minimum viewing time of about 9.5 seconds, even when
     Google Apps Script finishes immediately.
   - Full refresh loading has a minimum viewing time of about 6.5 seconds.
   - The progress continues while the backend is still working and gradually
     slows near 99% instead of freezing during normal loading.
   - 100% is shown only after the backend has finished.
   - Every percentage updates the seed, stem, trunk, branches, leaves, and apples.
   - When internet is lost, percentage movement stops, the tree falls, and then
     the existing No Internet Connection modal appears.
   - When internet returns, interrupted data sources are refreshed.

FILES THAT DO NOT NEED TO BE UPDATED
------------------------------------
4. Code.gs — NO CHANGE FOR THIS REVISION
   The Google Apps Script backend is included for complete-package installation,
   but loader behavior does not require a new Code.gs deployment.

5. assets/cares-logo.png — NO CHANGE FOR THIS REVISION
   Keep this exact file path:
       assets/cares-logo.png

FAST UPDATE METHOD

Upload and replace only these three files:
   index.html
   style.css
   script.js

Do not replace Code.gs only for this visual loader revision.

COMPLETE UPDATE METHOD
----------------------
Upload the full included folder and preserve this structure:

   index.html
   style.css
   script.js
   Code.gs
   README.txt
   UPDATE_GUIDE.txt
   assets/
       cares-logo.png

AFTER UPLOADING
---------------
1. Hard-refresh the browser using Ctrl + Shift + R.
2. Sign in to the dashboard.
3. Confirm the white loading card is gone.
4. Confirm the table and dashboard behind the loader are blurred.
5. Confirm the percentage visibly runs 1%, 2%, 3% without skipping.
6. Confirm the tree changes slightly at every percentage.
7. Confirm the loader does not close until backend data is ready and 100% is
   displayed.
8. Test offline behavior using browser DevTools:
      Network tab > change Online to Offline.
   Confirm that progress stops, the tree and branches fall, and the No Internet
   Connection modal appears after the fall animation.
9. Return DevTools to Online and press Retry. Confirm data refreshes.

IMPORTANT NOTES
---------------
- A percentage counter cannot continue beyond 100%. If an unusually slow backend
  is still unfinished after the loader reaches 99%, the loader remains active at
  99% with continuous tree/progress movement. It advances to 100% immediately
  after the backend finishes.
- The loader is intentionally visible for a minimum duration so fast data does
  not make the tree growth flash too quickly.
- Do not rename script.js, style.css, index.html, or the assets folder unless you
  also update their matching references.
