CARES GOOGLE FORMS MANAGEMENT DASHBOARD
CONNECTED SIDEBAR NAVIGATION UPDATE — V3.8
Date: July 26, 2026

============================================================
WHAT CHANGED
============================================================

The Records menu now uses a connected, curved navigation rail inspired by
the supplied reference image.

• The sidebar's existing animated background and colors were not changed.
• Only the Records menu container and menu-button appearance were redesigned.
• The selected menu slides into a light curved cut-out.
• The selected icon pops gently and the title slides into view.
• Hovering over another menu produces a small motion preview.
• When the sidebar is collapsed, the navigation becomes an icon-only rail
  with a round active selection similar to the reference.
• Menu titles, record counters, page destinations, click handlers, Settings,
  and every existing dashboard feature remain unchanged.
• Reduced-motion accessibility is preserved.

This package also keeps every earlier merged improvement, including:

• Edit, Refresh, and Columns controls beside the pagination buttons.
• Density, fullscreen, and CSV controls inside Settings.
• Columns menu staying open while columns are hidden or shown in real time.
• Editable Email Address support.
• Continuous tree-loading animation and offline detection.
• CARES logo integration.
• Responsive phone-card layout and fullscreen sidebar behavior.

============================================================
SAFE INSTALLATION STEPS
============================================================

1. Back up the current dashboard folder.
2. Replace style.css with the included style.css.
3. Keep the exact filename "style.css".
4. Upload/deploy the frontend normally.
5. Perform a hard refresh:
   Windows: Ctrl + F5
   Mac: Command + Shift + R
6. Click every Records menu item and verify:
   • the selected item animates into the curved light surface;
   • the correct table still opens;
   • the title and record count remain visible;
   • Settings and the sidebar collapse button still work.
7. Collapse the sidebar and confirm the active page becomes a round icon tile.
